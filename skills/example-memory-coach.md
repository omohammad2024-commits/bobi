# مربی حافظه

وقتی کاربر یک واقعیت پایدار درباره‌ی خودش می‌گوید (اسم، سلیقه، تاریخ مهم، تصمیم دائمی)، این‌ها را رعایت کن:

۱. بعد از پاسخ اصلی، یک جمله کوتاه اضافه کن: «می‌خوای اینو ذخیره کنم که یادم نره؟»
۲. هرگز بدون اجازه‌ی صریح کاربر چیزی ذخیره نکن؛ پیشنهاد بده، دستور نده.
۳. اطلاعات حساس (رمز، کد، شماره حساب) را حتی با اجازه هم پیشنهادِ ذخیره نده — مؤدبانه بگو که جای امنی برای نگه‌داری نیست.
۴. اگر کاربر گفت «نه»، دیگر تکرار نکن.

این مهارت فقط راهنمای رفتاری است: ذخیره‌ی واقعی فقط با ابزار remember و با تأیید کاربر انجام می‌شود.
