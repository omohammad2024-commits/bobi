# خلاصهٔ صبحگاهی (Proactive Morning Digest)

هرمس چنین چیزی ندارد: خلاصه‌ای فارسی، فعال و هرروزه که هر صبح ساعت ۸:۰۰
تهران وضعیت روز مالک را از منابع واقعی داخل خود بابی می‌سازد و می‌فرستد —
بدون اینکه مالک چیزی بپرسد.

## ابزار

`build_digest` (فقط مالک) — خروجی: متن فارسی قالب‌بندی‌شده، حداکثر
۲۵۰۰ نویسه (مناسب یک پیام تلگرام).

## بخش‌ها

| بخش | منبع | رفتار در نبود داده |
|---|---|---|
| ☀️ تاریخ و سلام صبحگاهی | `Intl.DateTimeFormat("fa-IR")` + Asia/Tehran | همیشه هست؛ بدون خطا |
| ✅ کارهای امروز | `Storage.listTasks` (فعال، اجرای بعدی در روز تهران) | «روز آرومی پیش روئه» |
| ⏰ یادآورها | `Storage.listReminders` (سررسید تا پایان امروز) | بخش حذف می‌شود |
| 🧠 پیشنهادهای حافظه | `ProposalStore.countPending` | بخش حذف می‌شود |
| 📊 مصرف ۲۴ ساعت اخیر | `UsageTracker` (دفتر مصرف، فقط فراداده) | بخش حذف می‌شود |
| 📰 سرخط خبرها — محتوای بیرونی | تابع تزریقی `searchHeadlines` (۳ خبر) | بخش حذف می‌شود |
| 💭 از حافظه‌ات | `Storage.listMemories` (۳ تازه‌ترین) | بخش حذف می‌شود |

هر منبع داخل `try/catch` خودش است: خرابی یک منبع فقط همان بخش را حذف
می‌کند و خلاصه را خراب نمی‌کند. اگر هیچ منبعی داده نداشت، باز هم خلاصه‌ای
معتبر (سلام + تاریخ + «امروز کاری نداری») تولید می‌شود.

## فعال‌سازی

۱. **ثبت ابزار در `src/index.ts`** (کنار `createUsageReportTool`):

```ts
createDigestTool({
  storage,
  proposalStore,
  isOwner: (userId) => identity.isOwner(Number(userId)),
  searchHeadlines: searchEnabled
    ? async (query, limit, signal) =>
        (await search.active().search({ query, limit, timeoutMs: 12_000, signal })).map((r) => ({
          title: r.title,
          url: r.url,
          snippet: r.snippet,
        }))
    : undefined,
}) as Tool<unknown, unknown>,
```

۲. **زمان‌بندی روزانه ۸:۰۰ تهران** — یکی از دو راه:

- آماده و پیشنهادی: `/blueprint run morning_digest` در چت مالک. این
  دستور یک `scheduled_task` با اکشن `agent` و پرامپت فارسی می‌سازد که
  به ایجنت می‌گوید `build_digest` را صدا بزند و متن را بفرستد.
- دستی: ابزار `schedule_task` با اکشن از نوع `agent`:

```json
{
  "name": "morning digest",
  "cron": "0 8 * * *",
  "timezone": "Asia/Tehran",
  "action": {
    "type": "agent",
    "chatId": "<chat id مالک>",
    "prompt": "ابزار build_digest را صدا بزن و متن خلاصهٔ صبحگاهی را همان‌طور که هست برایم بفرست."
  }
}
```

## امنیت

خلاصهٔ صبحگاهی دادهٔ خصوصی مالک را در خود دارد (کارها، یادآورها، خاطره‌ها،
مصرف)؛ پس **فقط و فقط به چت مالک** تحویل داده می‌شود. سه لایه:

1. **ابزار `ownerOnly` است** — پل احراز هویت کلید دسترسی را به هیچ
   غیرمالکی نمی‌دهد و ابزار در لیست ابزارهای غیرمالک دیده نمی‌شود.
2. **`run()` خودش مالکیت را دوباره چک می‌کند** (`isOwner` سمت سرور)؛
   حتی اگر کسی اکتور را دستی بسازد، رد می‌شود.
3. **مسیر تحویل، تحویل مالک زمان‌بند است**: ساخت `scheduled_task`
   فقط برای مالک مجاز است و اکشن `agent` شناسهٔ چت را از سمت سرور
   (چت فرستندهٔ دستور) می‌گیرد — مدل یا کاربر نمی‌تواند چت دیگری را
   نام ببرد. ابزار خودش هیچ چتی را نام نمی‌برد و چیزی ارسال نمی‌کند.

محتوای وب **دادهٔ شخص ثالث نامطمئن** است:
- بخش خبرها صراحتاً «محتوای بیرونی» برچسب خورده و با هشدار «حرف من
  نیستند» شروع می‌شود — هرگز شبیه دادهٔ مالک به نظر نمی‌رسد.
- از URL فقط **hostname** نمایش داده می‌شود؛ query string (که می‌تواند
  شناسهٔ نشست یا توکن حمل کند) هرگز وارد چت نمی‌شود.
- متن خبرها یک‌خطی و بریده می‌شود تا نتواند قالب پیام را بشکند.

هیچ رازی در میان نیست: منابع خلاصه (وظایف، خاطره، مصرف) اصلاً رمز
ندارند و سازندهٔ خلاصه محتوای بخش‌ها را لاگ نمی‌کند — فقط یک خط کوتاه
که کدام منبع رد شد.
