# فاز D3 — فایل‌های زمینه (Context Files)

فایل‌های مارک‌داونِ دست‌ساز مالک (به سبک `AGENTS.md` و `SOUL.md` هرمس) که در
هر نوبت، زیر یک سرفصل مشخص، به system prompt اضافه می‌شوند: قراردادهای پروژه،
نکته‌های لحن، هر چیزی که مالک می‌خواهد ایجنت همیشه بداند. مثل مهارت‌ها (A3)،
این‌ها هم **فقط متن راهنما** هستند — نه مجوز، نه کد.

## پیکربندی

`BOBI_CONTEXT_FILES`: فهرست مسیرها با جداکننده‌ی کاما. پیش‌فرض:

```
./AGENTS.md,./SOUL.md
```

این متغیر **مستقیماً از `process.env` خوانده می‌شود** (در `src/context/loader.ts`)،
نه از `config.ts` — پیکربندیِ سطحِ فرایند است، نه پیکربندیِ کاربر، و مرز فاز
ایجاب می‌کرد `config.ts` دست نخورده بماند.

## سقف‌ها

- هر فایل حداکثر **16KB**؛ فایل بزرگ‌تر با یک هشدار در لاگ **نادیده گرفته می‌شود**.
- مجموع تزریق حداکثر **8000 کاراکتر**؛ فایلی که از سقف رد شود در مرز سقف
  **بریده می‌شود** (با هشدار) و فایل‌های بعدی نادیده گرفته می‌مانند. ترتیب،
  ترتیبِ فهرستِ پیکربندی است — پس مالک با مرتب‌سازی، اولویت را کنترل می‌کند.
- فایلِ گمشده یا خوانده‌نشدنی **بی‌صدا نادیده گرفته می‌شود**: نصبِ تازه‌ای که
  هنوز فایل زمینه ندارد، خطا نمی‌گیرد.

## کش mtime و معنای snapshot

`ContextFileCache` دقیقاً الگوی `SkillCache` است: تا وقتی mtime هیچ فایلی
(یا وضعیت «گمشده بودن» آن) عوض نشده، همان فهرستِ قبلی برمی‌گردد؛ پس به‌ازای
هر پیام، I/O فایل‌سیستم تکرار نمی‌شود. فایلِ ویرایش‌شده از **نوبتِ بعد**
اعمال می‌شود — بدون ری‌استارت، بدون واچر.

**معنای snapshot:** فراخواننده (موتور گفت‌وگو) باید **به‌ازای هر نوبت، یک‌بار**
`cache.snapshot()` را صدا بزند و رشته‌ی برگشتی را در `PromptContext.contextFiles`
بگذارد. چون متن در لحظه‌ی ساختِ پرامپت منجمد می‌شود، ویرایشِ فایل **وسطِ نوبت**
پرامپتِ در حال اجرا را عوض نمی‌کند — نوبت همان متنی را نگه می‌دارد که با آن
شروع کرده است.

## تزریق در پرامپت

`prompt.ts` (فقط افزودنی، بدون تغییر رفتار قبلی):

- فیلد اختیاری جدید `PromptContext.contextFiles` — رشته‌ی ازپیش‌ساخته‌شده.
- بلاک بعد از مهارت‌ها/شخصیت و **قبل از** `extra` اضافه می‌شود، با سرفصل فارسی:

```
زمینه‌ی پروژه:
### AGENTS.md
...
```

`extra` همچنان آخر می‌ماند تا بتواند پیش‌فرض‌ها را بازنویسی کند. وقتی
`contextFiles` خالی یا undefined باشد، هیچ بلاکی اضافه نمی‌شود — پرامپتِ
«بدون فایل زمینه» بایت‌به‌بایت با قبل از D3 یکی است.

## نقطه‌ی اتصال (برای هماهنگ‌کننده)

`engine.ts` در این فاز **دست نخورده** باقی ماند. اتصالِ پیشنهادی، یک خط در
جایی است که `skillContext` ساخته می‌شود:

```ts
const contextFiles = this.contextFiles?.snapshot(); // ContextFileCache، ساخته‌شده در سازنده
// ...
systemPrompt: buildSystemPrompt({
  // ...
  ...(contextFiles !== undefined ? { contextFiles } : {}),
})
```

## امنیت

- فایل‌های زمینه **سطحِ پیکربندیِ تحتِ کنترلِ مالک‌اند** (دقیقاً مثل فایل‌های
  مهارت): هر کس که بتواند آن‌ها را بنویسد، می‌تواند رفتار ایجنت را در هر نوبت
  هدایت کند. فقط مالکِ سرور باید دسترسیِ نوشتن داشته باشد.
- **هرگز رمز در آن‌ها نگذارید**: محتوایشان در هر نوبت وارد پرامپت می‌شود، و
  پرامپت نشتی‌ترین سطحِ یک ربات است.
- سقف‌های کاراکتری، «بمبِ زمینه» (فایلِ غول‌پیکرِ تزریق‌شده) را به رد شدن
  تبدیل می‌کنند، نه به تزریق.
