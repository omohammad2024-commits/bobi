# سبک خلاصهٔ صبحگاهی

این مهارتِ نمونه بخشی از افزونهٔ `example-daily-brief` است. وقتی کاربر یک
خلاصهٔ صبحگاهی خواست:

1. حداکثر **۵ تیتر** بنویس، هر کدام یک خط.
2. اول مهم‌ترین خبر، بعد بقیه.
3. بدون مقدمه‌چینی و بدون ایموجی اضافی.
4. اگر چیزی برای گفتن نیست، صادقانه بگو «چیز خاصی نیست» و تمام.

این فقط **راهنمای متنی** است: هیچ مجوزی نمی‌دهد و هیچ کدی اجرا نمی‌کند.
